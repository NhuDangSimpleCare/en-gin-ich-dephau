Welcome to nginX (Bản Chạy Bằng Niềm Tin)!

Nếu bạn đang thấy trang này, nghĩa là con web server nginx đã được cài đặt thành công, nhưng dev chưa code xong hoặc backend vừa sập.

Tình trạng hệ thống:
  • RAM VPS: Còn đúng 12MB.
  • Database: Đang cầu nguyện.
  • Docker container: Exit code 137 cách đây 3 phút.

Để hệ thống hoạt động bình thường trở lại:

  • Không F5 liên tục kẻo cháy chip máy chủ.
  • Vui lòng chuyển khoản tiền cafe cho Sysadmin để mở khóa port.
  • Kiểm tra lại xem bạn có gõ nhầm domain sang web lậu không.

Cảm ơn vì đã không DDoS con server còm này.
